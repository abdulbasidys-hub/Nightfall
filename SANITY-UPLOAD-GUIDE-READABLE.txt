## How to add each image inside Studio

1. Open the relevant Project document and its Story & media tab.
2. For Cover media, choose Upload and select the specified cover PNG.
3. Fill Alternative text. For images with a focal subject, use crop/hotspot controls where helpful.
4. In Gallery, add an Image item and upload the next file. Repeat in the specified order, or reorder the gallery afterwards.
5. Enter alt text for each item and optional captions.
6. Publish only when the required fields and classification are correct.
7. Refresh the public project page and check desktop and phone layouts. If a cover is awkwardly cropped, choose a better-centered image or adjust the presentation after reviewing it.

Sanity saves edits as drafts. Publishing is the explicit step that makes the content public. Existing published projects keep their previous public version while you edit a new draft. The website's Presentation preview currently shows published content only, so an unpublished new project will not appear there.
